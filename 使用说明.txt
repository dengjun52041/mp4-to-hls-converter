============================================================
  涛涛转码箱 · 视频转 HLS 工具 — 使用说明
============================================================

【这是什么】
一个网页版视频转码工具：把 MP4 / MKV 等视频一键转成 HLS
自适应流（m3u8 + 分片）。转完可打包下载到本地，也可直接
上传到 Cloudflare R2。

------------------------------------------------------------
【第一步：启动工具】（实例不会自动跑，需手动启动一次）
------------------------------------------------------------
打开终端（JupyterLab 终端或 SSH 都行），执行这一句：

    bash /root/启动涛涛转码箱.sh

看到「涛涛转码箱已启动」就好了。
（等价命令：bash /root/taotao-transcoder/start.sh）

停止服务：bash /root/taotao-transcoder/stop.sh

------------------------------------------------------------
【第二步：打开网页界面】（服务端口 3000）
------------------------------------------------------------
方式一（推荐，AutoDL 端口映射）：
  1. 进入本实例的「详情页」
  2. 找到「自定义服务」/「端口映射」
  3. 添加端口 3000，点击生成的访问链接
  4. 浏览器打开即可看到转码界面

方式二（SSH 隧道，在你自己电脑上执行）：
  ssh -p <你的SSH端口> -L 3000:localhost:3000 root@<SSH地址>
  然后本地浏览器访问 http://localhost:3000

------------------------------------------------------------
【使用步骤】
------------------------------------------------------------
1. 打开网页后，把视频拖进上传区
2. 选择转码模式（原样切片 / H.265均衡 / H.265省空间 / H.264高兼容）
3. 勾选要输出的清晰度（可多选做自适应，只向下兼容不升清）
4. 选择编码器（自动 / GPU / CPU）
5. 点「开始转码」，等待进度条走完
6. 转完选「下载到本地(ZIP)」或「上传到 R2」

------------------------------------------------------------
【上传到 Cloudflare R2】
------------------------------------------------------------
点「上传到 R2」后填写：
  - Endpoint、Access Key ID、Secret Access Key
    （Cloudflare 后台 → R2 → 管理 R2 API 令牌 → 创建「对象读写」令牌获得）
  - 桶名（Bucket）、存放前缀（默认 hls）
勾选「记住」会把密钥存在你自己浏览器里，下次自动填充。
密钥只在上传时用，不会保存在服务器上。

------------------------------------------------------------
【关于 GPU 加速】
------------------------------------------------------------
是否启用 GPU 取决于本实例显卡是否开放了 NVENC。网页右上角
徽章会显示「GPU 可用」或「仅 CPU」。AutoDL 多数实例不开放
NVENC，此时自动走 CPU 编码，转码仍正常进行，只是速度较慢。
