============================================================
  涛涛转码箱 · 视频转 HLS 工具 — 使用说明
============================================================

【这是什么】
一个网页版视频转码工具：把 MP4 / MKV 等视频一键转成 HLS
自适应流（m3u8 + 分片）。有 NVIDIA 显卡自动走 GPU 硬件加速
（NVENC），没有显卡自动用 CPU。转完可打包下载到本地，也可
直接上传到 Cloudflare R2。

------------------------------------------------------------
【怎么打开网页界面】
------------------------------------------------------------
本工具开机已自动运行，服务端口是 3000。打开方式：

方式一（推荐，AutoDL 端口映射）：
  1. 进入本实例的「详情页」
  2. 找到「自定义服务」/「端口映射」
  3. 添加端口 3000，点击生成的访问链接
  4. 浏览器打开即可看到转码界面

方式二（SSH 隧道，本地电脑执行）：
  ssh -p <你的SSH端口> -L 3000:localhost:3000 root@<SSH地址>
  然后本地浏览器访问 http://localhost:3000

------------------------------------------------------------
【如果工具没自动运行】
------------------------------------------------------------
手动启动：  bash /root/taotao-transcoder/start.sh
停止服务：  bash /root/taotao-transcoder/stop.sh
查看日志：  cat /root/taotao-transcoder/server.log

------------------------------------------------------------
【使用步骤】
------------------------------------------------------------
1. 打开网页后，把视频拖进上传区
2. 选择转码模式（原样切片 / H.265均衡 / H.265省空间 / H.264高兼容）
3. 勾选要输出的清晰度（可多选做自适应，只向下兼容不升清）
4. 选择编码器（自动 / GPU / CPU）
5. 点「开始转码」，等待进度条走完
6. 转完选「下载到本地(ZIP)」或「上传到 R2」

------------------------------------------------------------
【上传到 Cloudflare R2】
------------------------------------------------------------
点「上传到 R2」后填写：
  - Endpoint、Access Key ID、Secret Access Key
    （Cloudflare 后台 → R2 → 管理 R2 API 令牌 → 创建「对象读写」令牌获得）
  - 桶名（Bucket）、存放前缀（默认 hls）
勾选「记住」会把密钥存在你自己浏览器里，下次自动填充。
密钥只在上传时用，不会保存在服务器上。

------------------------------------------------------------
【关于 GPU 加速】
------------------------------------------------------------
是否启用 GPU 取决于本实例的显卡是否开放了 NVENC。网页右上角
徽章会显示「GPU 可用」或「仅 CPU」。若显示仅 CPU，转码仍可
正常进行，只是速度较慢。
