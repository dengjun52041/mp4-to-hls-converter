# 涛涛转码箱

> 视频转 HLS 工具 · 来自 B站 UP主「涛涛碎碎念RE」（https://space.bilibili.com/3546981288905273）

把 MP4 等视频转成 HLS 自适应流的网页工具。GPU（NVENC）硬件加速，转完可**下载到本地**或**直接上传到 Cloudflare R2**。专为 AutoDL 等按量计费 GPU 实例设计，配合自定义镜像可做到开机即用。

## 功能

- 拖拽上传视频，自动识别时长 / 分辨率
- 4 种转码模式：原样切片 / H.265 均衡 / H.265 极限省空间 / H.264 高兼容
- 清晰度方案：自适应多档（最高到 480p，最多 4 档）或单档固定清晰度
- 只能向下兼容：按原视频分辨率动态给出可选档位，绝不升分辨率
- 实时转码进度条；转完可下载 ZIP 或上传 R2（带上传进度）
- R2 密钥在网页里填写，可勾选“记住”（只存你自己浏览器，不存服务器）
- 可选访问密码（在 `.env` 里设置 `TOKEN`）

## 转码模式怎么选

| 模式 | 体积 | 画质 | 适合 |
|---|---|---|---|
| 原样切片 | 与原片相同 | 无损 | 原片码率已合理、赶时间 |
| H.265 均衡（默认） | 约原片一半 | 肉眼无损 | 大多数情况 |
| H.265 极限省空间 | 比均衡再小 30% | 良好 | 存储/流量敏感 |
| H.264 高兼容 | 比 H.265 大 40% | 良好 | 老设备/老浏览器 |

## 在 AutoDL 上使用（推荐流程）

1. **租实例**：AutoDL 控制台 → 租一台按量计费实例（选有 NVIDIA GPU 的，机房尽量选网络好的）。
2. **上传项目**：把整个项目文件夹上传到实例（可用平台网页文件管理，或 `scp`）。假设放在 `/root/hls-transcoder`。
3. **一键部署**：在实例终端执行
   ```bash
   cd /root/hls-transcoder
   bash deploy.sh
   ```
   脚本会自动装好 ffmpeg（含 NVENC）、Node、依赖，并设置开机自启。
4. **放行端口**：在 AutoDL 控制台把 `3000` 端口映射/放行（平台叫“自定义服务”）。
5. **打开网页**：浏览器访问映射后的地址，拖入视频即可转码。
6. **保存镜像（关键）**：全部测试没问题后，**先关机**，在实例“更多操作”里点“保存镜像”。以后租新实例时选这个自定义镜像，开机就是现成环境，不用再部署。
7. **用完关机**：关机不扣 GPU 费用，数据保留。

> 提示：AutoDL 机房在大陆，上传到 Cloudflare R2 属跨境流量，速度约 1–5 MB/s。转码本身很快（GPU 下 1 小时视频约 1–3 分钟），主要耗时在上传。工具已用并发上传尽量拉满带宽。

## 本地运行（Windows / 测试用）

需要先安装 [Node.js](https://nodejs.org/)（≥18）和 [ffmpeg](https://ffmpeg.org/)（加入 PATH）。

```bash
npm install
npm start
```

打开 http://localhost:3000 即可。本地一般无 NVIDIA GPU，会自动用 CPU 编码（较慢，仅适合测试）。

## 配置（.env）

| 变量 | 说明 |
|---|---|
| `PORT` | 网页端口，默认 3000 |
| `TOKEN` | 访问密码，留空不启用（公网部署建议填写） |
| `FFMPEG_PATH` / `FFPROBE_PATH` | ffmpeg 路径，留空用系统 PATH |

R2 的密钥**不在这里配置**，在网页“上传到 R2”弹窗里填写。

## R2 密钥从哪来

Cloudflare 后台 → R2 → 右侧“管理 R2 API 令牌” → 创建令牌，权限选“对象读写”。会得到：
- Access Key ID
- Secret Access Key（只显示一次，记得保存）
- Endpoint（形如 `https://账户ID.r2.cloudflarestorage.com`）

桶名（Bucket）就是你在 R2 里建的桶的名字。存放前缀默认 `hls`，转出来的文件会放在 `桶/hls/视频名/` 下。

## 目录结构

```
├── server.js          主服务
├── lib/ffmpeg.js      转码模块
├── lib/r2.js          R2 上传模块
├── public/index.html  网页界面
├── deploy.sh          一键部署（AutoDL）
├── start.sh / stop.sh 手动启停
├── uploads/           上传临时目录（自动清理）
└── work/              转码输出临时目录
```

## 常见问题

- **网页打不开**：确认 3000 端口已在平台放行；`cat server.log` 看报错；无 systemd 环境需手动 `bash start.sh`。
- **转码很慢**：检查是否在用 GPU（网页顶部徽章显示“GPU 硬件加速”才是 GPU）。CPU 模式会慢很多。
- **R2 连接失败**：核对 Endpoint / 密钥 / 桶名；确认令牌权限是“对象读写”。
- **8K 选项不出现**：8K 仅在 H.265 模式且原视频≥8K 时可选；H.264 模式最高 4K。
