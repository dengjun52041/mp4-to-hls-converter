📺 这是一个视频转 HLS 工具 收起 ▲

把 MP4、MKV 等视频一键转成 HLS 自适应流（m3u8 + ts 分片）。转完可打包下载到本地，也可直接存入 Cloudflare R2，即转即用。

为什么要转成 HLS？
  • 自适应清晰度：一个播放链接搞定全部。播放器按观众网速在 4K / 1080p / 720p / 480p 间无缝切换，弱网也不卡。
  • 秒开不等待：视频切成小分片边下边播，点开就能看，不用等整个文件加载完。
  • 天生适合做视频站：影视站、课程站、个人点播的主流方案；配合对象存储（R2 / OSS）和签名链接还能防盗链。
  • GPU 加速转码飞快：有 NVIDIA 显卡走硬件编码，一小时视频几分钟搞定；没显卡也能用 CPU 稳稳转出。
